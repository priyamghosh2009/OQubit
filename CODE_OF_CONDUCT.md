# Code of Conduct

## OQubit Community Code of Conduct

The OQubit project is committed to providing a welcoming, respectful, and constructive environment for everyone who participates in the project.

This Code of Conduct applies to all contributors, maintainers, users, reviewers, and community members participating in OQubit spaces, including GitHub repositories, issues, pull requests, discussions, documentation, and other project-related communication.

## Our Standards

We encourage behavior that contributes to a positive and productive technical community.

Examples of expected behavior include:

* Being respectful and considerate toward others.
* Communicating clearly and constructively.
* Welcoming people with different levels of experience.
* Giving and receiving technical feedback professionally.
* Focusing discussions on ideas, implementations, evidence, and technical reasoning.
* Respecting different approaches to solving technical problems.
* Giving appropriate credit to the work of others.
* Following the project's licensing and contribution requirements.
* Reporting security or safety concerns responsibly.
* Helping maintain a collaborative environment for quantum-computing research and software development.

## Unacceptable Behavior

The following behavior is not acceptable within the OQubit community:

* Harassment, intimidation, or personal attacks.
* Discriminatory or hateful conduct toward any person or group.
* Trolling, deliberate disruption, or repeated bad-faith participation.
* Publishing or sharing another person's private information without permission.
* Impersonating another contributor, maintainer, organization, or project.
* Plagiarism or intentionally misrepresenting another person's work as one's own.
* Deliberately submitting malicious code or changes intended to compromise users or project infrastructure.
* Unwelcome sexual or other inappropriate conduct.
* Threats of violence or other threatening behavior.
* Any other conduct that violates applicable laws or project policies.

Technical disagreement is not, by itself, unacceptable behavior. Contributors are encouraged to challenge implementations, designs, assumptions, and technical conclusions while keeping discussions respectful and focused on the work.

## Scientific and Technical Integrity

OQubit is a python library and research-oriented project. Contributors should make a reasonable effort to maintain technical and scientific integrity.

When submitting technical claims, benchmarks, research material, or algorithm implementations, contributors should:

* Clearly distinguish tested results from theoretical expectations.
* Avoid intentionally misleading benchmarks or demonstrations.
* Cite relevant external work when appropriate.
* Preserve attribution and copyright notices.
* Clearly identify experimental or incomplete implementations where relevant.
* Correct significant errors when they are discovered.

Disagreement about technical or scientific conclusions should be handled through evidence, reproducible experiments, documentation, and constructive discussion.

## Project Spaces

This Code of Conduct applies to project-related spaces, including but not limited to:

* GitHub issues
* Pull requests
* GitHub Discussions
* Code reviews
* Documentation contributions
* Project meetings or events
* Official project communication channels
* Other spaces where an individual is representing the OQubit project

Project maintainers may take appropriate action when behavior outside official project spaces directly affects the safety or ability of community members to participate in OQubit.

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, report it to the OQubit project maintainers through the project's designated private reporting channel.

When making a report, provide as much relevant information as reasonably possible, such as:

* A description of the incident.
* The date and approximate time.
* The project space where it occurred.
* Relevant links or references.
* Any additional context that may help the maintainers understand the situation.

Reports will be handled as confidentially as reasonably possible.

Please do not publicly disclose sensitive information about an incident while requesting moderation.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the circumstances, maintainers may:

1. Ask participants to stop inappropriate behavior.
2. Remove or edit content that violates project standards.
3. Close or restrict discussions, issues, or pull requests.
4. Temporarily restrict participation.
5. Permanently restrict participation in project spaces.
6. Take other reasonable actions necessary to protect the project community.

Enforcement decisions will consider the nature, severity, frequency, and context of the reported behavior.

## False or Malicious Reports

Reports should be made in good faith.

Knowingly submitting false reports, fabricating evidence, or deliberately abusing the reporting process may itself constitute a violation of this Code of Conduct.

A report made in good faith will not be considered a violation merely because the maintainers ultimately determine that the reported behavior did not violate this Code of Conduct.

## Maintainer Responsibilities

OQubit maintainers are expected to:

* Apply this Code of Conduct consistently.
* Treat reports seriously and respectfully.
* Avoid unnecessary disclosure of private information.
* Provide contributors with a reasonable opportunity to explain relevant circumstances when appropriate.
* Make enforcement decisions based on the available information and the project's interests.
* Maintain a constructive environment for technical collaboration.

## Scope

This Code of Conduct does not replace the OQubit project's:

* `LICENSE`
* `CONTRIBUTING.md`
* `SECURITY.md`
* GitHub repository policies
* Applicable laws or regulations

Where another project policy provides more specific requirements, that policy may also apply.
