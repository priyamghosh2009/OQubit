# OQubit Documentation

Welcome to the **OQubit documentation**.

OQubit is a Python-based quantum computing simulator designed for building, simulating, and experimenting with quantum states, gates, circuits, measurements, and quantum algorithms.

## Documentation

### Getting Started

Start here if you are new to OQubit.

* [Installation](getting-started/installation.md) — Install OQubit and set up your environment.
* [Quickstart](getting-started/quickstart.md) — Run your first OQubit program.

### User Guide

Learn how to use the main components of OQubit.

* [Qubits](user-guide/qubits.md) — Create and work with individual qubits.
* [StateVectors](user-guide/statevectors.md) — Represent and manipulate multi-qubit states.
* [Gates](user-guide/gates.md) — Work with quantum gates and operators.
* [Circuits](user-guide/circuits.md) — Build quantum circuits.
* [Measurement](user-guide/measurement.md) — Measure states and sample outcomes.
* [Algorithms](user-guide/algorithms.md) — Use quantum algorithms provided by OQubit.
